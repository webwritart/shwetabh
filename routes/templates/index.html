Custom Multi-Texture Shader

As Unity 6.3 deprecated POLYBRUSH I created my own URP shader with the following features:

  • 4 layer textures with all the main maps (Albedo, Metallic-smoothness, Normal)
  • Additional color multiplier with each Albedos to for final Albedo adjustment
  • Masking using RGB Map
  • Separate Metallic, Smoothness and Normal intensity controller for each Textures
  • Unified tiling input (common for all maps) for each texture
  • Optimized Texture samples using SamplerState
